# Benchmarks

Benchmarking infrastructure and results. No results are fabricated.

- `benchmarks/synthetic-data/` — synthetic data generators (where explicitly requested).
- `benchmarks/baselines/` — baseline algorithm specifications and TODO stubs (developer-owned implementations).
- `benchmarks/configurations/` — benchmark configurations.
- `benchmarks/results/` — measured results (committed only when reproducible).

See `docs/algorithm-evaluation.md`.
