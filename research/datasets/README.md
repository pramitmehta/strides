# Datasets

This directory holds dataset metadata only. Raw and processed data are gitignored.

- `dataset-register.yaml` — canonical registry of all candidate datasets.
- `manifests/` — per-dataset checksums and file lists (committed after acquisition).
- `schemas/` — JSON schemas for `imu_sample` and `step_event`.

See `RESEARCH_AND_DATASETS.md` for the data policy and acquisition checklist.
