# Algorithms

Overview of the pure-JVM algorithmic SDK (`algorithms/`). Algorithm implementations are developer-owned; this module currently contains interface and domain-model scaffolding only.

## Modules
- `:algorithms:cadence` — running cadence and sensor processing (first developer-owned algorithm).
- `:algorithms:curriculum` — adaptive curriculum optimization.
- `:algorithms:biomechanics` — exercise form recognition.
- `:algorithms:coach` — on-device AI coach prompt/heuristic builder.

See `docs/problem-formulation.md` and `docs/mathematical-models.md`.
